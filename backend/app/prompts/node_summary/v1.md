Write the one-line caption that sits under each skill in a knowledge tree.

Each block below is one node: its slug, the heading the book gave it, and an
excerpt of the text that node owns. The excerpt comes from a PDF text layer, so
formulae arrive flattened into nonsense — `C = AB = A h b1 b2 · · · bp i` is a
matrix display, not a sentence. Read past it.

## What a caption is for

A learner reads it to decide whether they already know this, and to remember what
it was after a week away. So it must say **what the thing is**, in the book's own
terms.

- Say what the node's own heading names. If the heading is "The KKT Theorem", the
  caption is about the KKT theorem — not about the epigraph the section happens
  to open with, and not about the worked example underneath it.
- One or two sentences. A caption, not an abstract.
- Plain prose. Never copy a formula; describe what it does if it matters.
- No filler openings: not "This section covers…", not "In this chapter we…".
  Start with the thing itself.

## Grounding

Everything you write must be supported by that node's own excerpt. You are
rewording text you can see, not recalling what you know about the subject. If an
excerpt is too mangled or too thin to say anything true about it, **omit that
node entirely** — a missing caption falls back to a deterministic one, which is
strictly better than a confident invention.

## Slugs are closed

`slug` must be copied exactly from a block below. A slug that is not in the list
is discarded, so inventing one wastes the caption.
